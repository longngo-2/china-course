# Phương pháp học

## 1. Tận dụng âm Hán Việt
Phần lớn từ vựng học thuật tiếng Trung có âm Hán Việt tương ứng. Mỗi từ mới trong khóa đều kèm cột **Hán Việt**.
- Dùng để đoán nghĩa: 经济 *kinh tế*, 图书馆 *đồ thư quán* → thư viện.
- Cẩn thận “bạn giả”: 爱人 *ái nhân* = vợ/chồng; 新闻 *tân văn* = tin tức; 东西 *đông tây* = đồ vật.

## 2. Lặp lại ngắt quãng (SRS)
- Mỗi ngày 15–20 phút Anki; thêm 10–20 thẻ mới/ngày tùy chặng.
- Thẻ gồm: chữ Hán → pinyin + nghĩa + Hán Việt + câu ví dụ + audio.

## 3. Input dễ hiểu (Comprehensible Input)
- Nghe/đọc tài liệu hiểu được ~90%: graded readers, podcast cho người học, phim có phụ đề Trung.

## 4. Shadowing cho phát âm
- Nghe 1 câu → nhại theo ngay → ghi âm → so sánh. Tập trung thanh điệu và ngữ điệu cả câu.

## 5. Nhịp học gợi ý (~60 phút/ngày)
| Thời lượng | Hoạt động |
|---|---|
| 15' | Ôn Anki |
| 20' | Học bài mới (template bài học) |
| 15' | Nghe / đọc input |
| 10' | Shadowing hoặc viết chữ |
